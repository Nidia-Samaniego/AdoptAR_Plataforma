# AdoptAR 🐾

¡Bienvenido al repositorio oficial de **AdoptAR**! Una plataforma web centralizada diseñada para conectar refugios de animales, rescatistas independientes y personas interesadas en la adopción responsable de mascotas en Argentina.

---

## 📂 Estructura del Proyecto

El repositorio está organizado de forma limpia y modular siguiendo los estándares profesionales requeridos:

*   **`_Raíz del repositorio_`**
    *   📁 **`backend/`**: API REST y lógica de negocio desarrollada con Node.js y Express.
    *   📁 **`frontend/`**: Interfaz de usuario interactiva y moderna construida con React, TypeScript y Vite.
    *   📁 **`docs/`**: Documentación técnica, informes de avance, diagramas entidad-relación y manuales del proyecto.
    *   📄 **`README.md`**: Presentación general del proyecto (este archivo).

---

## 🛠️ Tecnologías y Stack Utilizado

### Frontend
*   **React** (Biblioteca para la interfaz)
*   **TypeScript** (Tipado estático para código robusto)
*   **Vite** (Herramienta de construcción ultra rápida)

### Backend
*   **Node.js** (Entorno de ejecución)
*   **Express** (Framework para la API)

## 🚀 Requisitos Previos e Instalación

Para ejecutar este proyecto de forma local, necesitás tener instalado **Node.js** v18 o superior y **npm**.

### 1. Clonar el repositorio
```bash
git clone https://github.com/Nidia-Samaniego/AdoptAR_Plataforma.git
cd AdoptAR_Plataforma
```

### 2. Ejecutar el Frontend
```bash
cd frontend
npm install
npm run dev
```
